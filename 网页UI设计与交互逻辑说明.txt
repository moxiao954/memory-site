3. 全局背景系统（含动效）
--------------------------------------------------------------------------------
3.1 光斑层 .ambient-glow
   - 三个 radial-gradient 椭圆光斑叠加：
       左上 12%10%  紫色 rgba(168,85,247,0.15)
       右下 85%78%  青色 rgba(0,229,255,0.15)
       中央 55%45%  粉色 rgba(244,114,182,0.08)
   - filter: blur(120px)（超大模糊制造氛围光）
   - 动效：keyframes ambient-drift，20s ease-in-out infinite alternate
       0%   translate(0,0)   scale(1)
       50%  translate(2%,-2%) scale(1.06)
       100% translate(-2%,2%) scale(1)
     → 光斑整体缓慢漂移 + 轻微缩放，营造"呼吸感"

3.2 粒子层 #particles（JS 生成）
   - 生成数量：30~40 个（随机）
   - 粒子规格：直径 2~4px 圆点；颜色随机取 青/紫/白 三色之一；
     透明度 0.3~0.8；水平位置 left 用百分比(0-100%)保证随视口缩放；
     初始 top 随机 0-100%
   - 动画：keyframes particle-float，周期 12~20s linear infinite，
     使用「负延迟」(0~-20s) 让页面一打开粒子就满屏分布而非从底部冒出来。
       keyframes particle-float：
         0%   translate3d(0,0,0)
         25%  translate3d(18px,-26vh,0)
         50%  translate3d(-14px,-52vh,0)
         75%  translate3d(20px,-78vh,0)
         100% translate3d(0,-104vh,0)
     → 粒子缓慢上升 + 左右摆动（类似浮尘/星光）
   - 交互：鼠标移动时，距离 <120px 的粒子被"排斥"：
       力 = (120 - dist)/120 × 14px，方向由鼠标→粒子向量决定
       （越近推力越大；用 requestAnimationFrame 节流，同帧只计算一次）
   - 性能：粒子带 will-change: transform, opacity

4. 页面进入动画（全站统一）
--------------------------------------------------------------------------------
CSS 默认状态：.page-main 的所有直接子元素 opacity:0 + translateY(20px)
JS 在 DOMContentLoaded 后用 requestAnimationFrame 给 .page-main 加 .loaded
触发后：子元素 0.6s ease-out 渐显并上移到原位，按 nth-child 顺序递增延时：
  第1个 +0.1s / 第2个 +0.2s / ... / 第6个 +0.6s
  → 从上到下依次浮现的"错落入场"

9. 时间线组件（DIARY 全量版 + 首页紧凑版共用，数据驱动）
--------------------------------------------------------------------------------
9.1 数据结构（js/main.js 的 timelineData 数组，按时间升序）
  [
    { time:"2026.07", title:"...", desc:"...", link:"https://..." },  // link 可空
    ...
  ]
  新增记录只需在该数组末尾加一行，无需改 HTML。

9.2 布局算法（renderTimeline 函数）
  - 按 time 字符串升序排序（最早在左、最近在右）
  - maxItems>0 时只保留最近 N 条
  - 节点上下交错排布：偶数索引(top)在上、奇数索引(bottom)在下
  - 中央一条横向渐变线 .tl-line（紫→青 2px，发光）
  - 每个节点：圆点 .tl-dot（16px，径向渐变白高光→青，底边框配色，青色辉光）
    + 玻璃卡片 .tl-card
  - 最后一个节点标记为"最新"：圆点变翡翠绿 + 时间变绿 + 追加绿色"最新"角标
  - 卡片内容：时间、标题、描述（3 行截断，首页紧凑版 2 行）、可选"了解更多 →"链接

9.3 点亮动画（依次点亮）
  - 总时长不超过 2s：totalMs = min(2000, 350×节点数)
  - 每节点 animation-delay = totalMs/(n-1) × index（递增）
  - 触发 .animate 类 → keyframes tl-reveal（0.8s，弹性曲线 cubic-bezier(0.34,1.56,0.64,1)）：
      0%   opacity:0  translateY(30px) scale(0.95)  blur(4px)
      100% opacity:1  translateY(0)    scale(1)     blur(0)
    → 节点从下方模糊浮现 + 轻微放大，依次点亮整条时间线
  - 首页概览版 animated:false（不播动画，直接显示）

9.4 悬停反馈
  - 卡片 hover：边框变青、青色辉光 + 内嵌高光、上移 4px
  - 链接 hover：translateX(4px) 右移 + 青色文字辉光
  - 空数据状态：保留时间线横线框架，中央显示"待开始记录"提示

9.5 安全：所有数据经 escapeHtml() 转义后插入 DOM，防特殊字符破坏结构

15. JS 交互事件总表
--------------------------------------------------------------------------------
| 事件                | 触发对象          | 行为                                           |
|---------------------|-------------------|------------------------------------------------|
| DOMContentLoaded    | document          | 依次启动 initPageReveal/initParticles/initCounters/initMagnetic |
| (rAF)               | .page-main        | 加 .loaded，子元素错落入场                     |
| mousemove           | window            | 120px 内粒子被排斥（rAF 节流）                  |
| mousemove/mouseleave| .magnetic         | 按钮磁吸跟随 / 归位                            |
| 加载完成            | .stat-num         | 数字 0→目标 1.5s 计数动画                       |
| 加载完成            | #particles        | 生成 30-40 粒子并启动漂浮动画                   |
| hover               | .card/.tl-card    | 上浮 + 辉光 + 3D 倾斜                           |
| hover               | .avatar           | 光环旋转动画启动、图片饱和增强                  |
| hover               | .card-placeholder | "+" 旋转 90°                                   |
| hover               | 页脚/文字链接     | 下划线滑出 + 变色青色                          |

16. 一键复现要点（给 AI 的 checklist）
--------------------------------------------------------------------------------
1) 建 5 个页面，共享同一套 <nav>/<footer>/<div class="ambient-glow">/<div id="particles">
2) 设计令牌全部走 :root 变量，动画元素加 will-change
3) 背景三层：渐变底色 + 光斑(blur120 + 20s 漂移) + 粒子(负延迟满屏)
4) 导航/卡片/按钮统一玻璃拟态：blur + 半透明底 + 细描边 + 辉光
5) 主色青 #00E5FF、辅色紫 #A855F7，渐变一律 135°/160° 方向
6) 动效节奏：进入=stagger，时间线=依次点亮，骨架=shimmer，
   弹簧类交互用 cubic-bezier(0.34,1.56,0.64,1)
7) 数据驱动：时间线只改 timelineData 数组；所有动态文本先 escapeHtml
8) 加 @supports not (backdrop-filter) 降级，保证旧浏览器可用
