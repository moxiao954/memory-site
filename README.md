## ✍️ 如何记录一条学习轨迹（最重要！）

**只需要改一个文件：`js/timeline.js`**

1. 用记事本（或任意文本编辑器）打开 `js/timeline.js`。
2. 找到 `timelineData` 数组（文件里有中文注释说明）。
3. 在数组末尾、最后一个 `}` 的后面加上一个英文逗号 `,`，然后**复制下面这行**并粘贴：

```javascript
  {
    time: "2026.08",
    title: "学到了什么（一句话）",
    desc: "一两句补充说明",
    link: ""
  }
```

4. 把里面的内容改成你真实的记录（`time` 填年月，如 `"2026.09"`）。
5. 保存文件 → 打开 GitHub Desktop → 提交（Commit）→ 推送（Push）。
6. 等约 1 分钟，刷新网站就能看到新节点出现在时间线最右侧（自动从左到右依次点亮）。

> ⚠️ 注意：
> - `time` 必须是"年.月"格式，如 `"2026.08"`。
> - 节点会自动按时间从左到右排列（最早在左、最近在右），所以新增记录按时间放即可，无需手动排序。
> - `link` 是可选的文章/项目链接；留空 `""` 就不显示链接。
> - 当前 `timelineData` 里有一条标题带 **"示例"** 的演示数据，正式开始记录时可以把它删除（连同它后面的逗号一起删）。

## 🚀 如何更新网站（发布新内容）

你只需要学会 GitHub Desktop 这一个工具：

1. 打开 GitHub Desktop，会看到本网站的改动列表。
2. 左下角填写一句"本次改了什么"（比如：添加了 8 月学习记录）。
3. 点击 **Commit to main**（提交）。
4. 点击右上角 **Push origin**（推送）。
5. 完成！约 1 分钟后线上网站自动更新，访客就能看到新版。

不需要敲任何命令，全程图形界面。

## 🧭 常见问题

**Q：改完 timeline.js 后网站没变化？**
A：先确认你已用 GitHub Desktop 点击了"推送"。推送后需要约 1 分钟构建时间，稍等再刷新；如果刷新没变，按 Ctrl+F5 强制刷新清除浏览器缓存。

**Q：加错了一条记录想删掉？**
A：打开 `js/timeline.js`，删掉那行即可（注意删除后要在前一条后面保留英文逗号），然后提交、推送。

**Q：想改网站文字（比如联系方式）？**
A：用记事本打开对应的 html 文件（如 `about.html`），找到文字直接改，保存、提交、推送。
