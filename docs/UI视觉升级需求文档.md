# memory-site UI 视觉升级需求文档 v2.0

> 版本：v2.0
> 日期：2026-08-11
> 状态：待实施
> 风格方向：深色底 + 暖色单高光 + 纵向骨架
> 执行对象：Codex harness + DeepSeek V4 Flash

## 1. 目标

- 解决当前“分区线全是横向、页面割裂、配色不够高级”的问题。
- 建立统一的深色底 + 暖色单高光体系，让全站视觉安静但有高光点缀，不沉闷。
- 用本地“得意黑”提升关键标题的艺术感，正文保持易读黑体。
- 移除标题随机刷字故障、卡片白色虚化高光、学习日记“了解更多”入口。
- 让日记横向滑条更显眼，并让时间线放大动效更连贯。

## 2. 非目标

- 不做移动端适配，保留 `min-width: 1200px`。
- 不实装项目筛选逻辑、博客文章列表、评论或搜索。
- 不引入框架、构建工具、CDN 或位图素材。
- 不实现真实折射（SVG displacement map），只用 CSS 可稳定实现的全套玻璃质感。
- 不新增除本地得意黑以外的字体文件。
- 不保留动态故障效果和任何周期性随机文字。

## 3. 配色系统

### 3.1 比例

- 60%：深色中性底，作为整页舞台。
- 30%：表面、玻璃和内容区。
- 10%：暖金高光、CTA、活动状态和边框强调。

### 3.2 统一强调色

全站 5 个页面统一使用同一套暖色单高光，不再按页面切换青、紫、品红、琥珀等霓虹色。

### 3.3 颜色表

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景最深色 | `#0C0F14` | 页面主舞台 |
| 背景表面色 | `#161A21` | 玻璃与内容表面 |
| 抬升表面 | `#1D222B` | 弹层、导航等更高层级 |
| 主文字 | `#F4F1EA` | 暖白，保证对比度 |
| 次级文字 | `#B9B4A8` | 说明与辅助内容 |
| 主高光 | `#E3B36D` | 暖金，用于边框、CTA、活动态 |
| 亮高光 | `#F2D394` | 更亮的高光，用于悬停与标题强调 |

- 区块背景使用低透明度暖金（约 6%-14%）。
- 全亮暖金只用于文字强调、边框发光、按钮和活动状态。

## 4. 字体系统

### 4.1 本地字体

- 从 atelier-anchor/smiley-sans 官方 Releases 下载 `SmileySans-Oblique.ttf.woff2`，放入 `fonts/`。
- 保留 SIL Open Font License v1.1 许可说明。
- 通过 `@font-face` 引入，不依赖外部 CDN。

### 4.2 应用范围

得意黑仅用于关键标题：

- `.hero-title`
- `.page-title`
- `.section-title`
- `.cta-section h2`
- `.tl-title`

正文保持 `Inter` 与微软雅黑回退，保证长文可读性。

### 4.3 排版要求

- 得意黑标题适当增加行高，避免斜切字形拥挤。
- 标题不得产生溢出、遮挡或与周围元素重叠。
- HUD 标签继续使用等宽字体：`ui-monospace, 'Cascadia Mono', Consolas, monospace`。

## 5. 布局系统

### 5.1 结构

主要区块统一使用：

```html
<section class="zone zone-xxx">
  <div class="zone-inner">
    <!-- 原内容 -->
  </div>
</section>
```

- `.zone`：全宽，只承载内容区和纵向骨架。
- `.zone-inner`：最大宽度 1160px，水平内边距 24px。
- `#full-timeline`、`#home-timeline`、`#particles` 等 ID 保持不变。

### 5.2 纵向骨架

- 删除 `.zone::before` 整条横向渐变光弧和 `.zone::after` 横向扫光。
- 改为 `.zone-inner` 左侧纵向渐变细线，作为全站统一的分区骨架。
- 区块之间保留 72-96px 中性深色空档，靠留白和纵向线区分。
- HUD 标签与左侧纵向线对齐，形成连续的视觉引导。

### 5.3 首页 hero

- 移除 hero 中产生“独立方框”的伪元素背景。
- 标题和说明文字直接放在页面上，不再套独立背景盒。
- 统计区改为连续数据行，用竖向细分隔线连接，避免碎片感。

### 5.4 页面统一

- 5 个页面使用同一套纵向骨架和间距规则。
- 不再使用整条横向色带、横向光弧或横向扫光作为主要分区方式。

## 6. 玻璃与悬停

### 6.1 三级玻璃

| 级别 | 用途 | blur | 饱和度 | 透明度 |
|---|---|---|---|---|
| `glass-sm` | 角标、筛选按钮、小胶囊 | 8px | 1.3 | 约 20% |
| `glass-md` | 卡片、时间线卡片、项目卡片 | 18px | 1.5 | 约 42% |
| `glass-lg` | 导航、CTA 面板、放大弹层 | 26px | 1.7 | 约 62% |

### 6.2 玻璃层构成

每块玻璃保留：

1. 半透明深色渐变底。
2. 1px 暖色细边框。
3. 顶部 1px 内高光。
4. 左上柔和高光斜线。
5. 底部深色投影和内侧暗影。

### 6.3 卡片悬停

- 不再铺整层白色虚化底。
- 悬停时使用暖金渐变描边、轻微上浮（2-4px）和低透明度暖色光标高光。
- 高光跟随鼠标通过 `--gx/--gy` 变量实现，透明度控制在 5%-8%。

## 7. 学习日记交互

### 7.1 删除外部链接

- 删除卡片和放大弹层中的“了解更多”及所有外部链接。
- 现有 `timelineData` 中的 `link` 字段一并移除。
- 点击卡片直接打开完整内容，不跳转外部页面。

### 7.2 横向滑条

- 日记横向滚动区提供显眼的自定义滑条轨道和暖色滑块。
- 增加左右箭头和滚动进度提示。
- 拖动或滚动时，JS 同步更新箭头可用状态与进度条。

### 7.3 放大弹层

- 用 FLIP/transform 方式从原卡片位置平滑放大到弹层目标位置。
- 使用统一缓动 `cubic-bezier(0.22, 1, 0.36, 1)`，时长约 420ms。
- 关闭动画反向执行，避免 left/top/width 分别变化造成的顿挫。

## 8. 动效规则

- 页面进入：保持错落渐显。
- 区块入场：轻微上移渐显，不做强缩放。
- 卡片悬停：上浮、暖金描边、光标高光跟随。
- 标题：只使用稳定渐变和文字光晕，不出现随机刷字。
- 学习日记：保留依次点亮动画，同时支持流畅放大与关闭。

## 9. 可访问性与降级

- `prefers-reduced-motion: reduce`：关闭粒子、扫光、滚动动画和放大弹层动画。
- `prefers-reduced-transparency: reduce`：玻璃改为近实色深底，降低或关闭模糊。
- `@supports not (backdrop-filter)`：使用近实色深底，保持可读。

## 11. 验收标准

- 桌面宽度 1200px 和 1440px 下，5 个页面均正常，无横向溢出、无文字重叠。
- 全站只使用深色底 + 暖色单高光，不再出现青紫霓虹和随机刷字。
- 页面中不存在 `.tl-link`，不存在 `glitch-title` 相关结构或样式。
- `fonts/SmileySans-Oblique.ttf.woff2` 请求 200，关键标题使用得意黑。
- 日记滑条轨道、滑块、箭头和进度可见可用。
- 时间线点击放大和关闭动画连贯，弹层完整显示内容。
- 浏览器控制台无报错，CSS、JS、图片、字体请求全部 200。
- reduced-motion 和 reduced-transparency 降级正常。
