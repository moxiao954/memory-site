# memory-site UI 视觉升级需求文档

> 版本：v1.0
> 日期：2026-08-11
> 状态：已完成（2026-08-11）
> 风格方向：赛博未来 + 方案 A 清透玻璃
> 执行对象：Codex harness + DeepSeek V4 Flash

## 1. 目标

- 在保留现有深蓝黑 + 青紫霓虹的赛博未来风格下，解决“整页同色”和“区块像一坨”的问题。
- 用 Apple Liquid Glass 的思路升级玻璃卡片：`blur + tint + depth + specular + sheen` 组合，而不是只加模糊。
- 加入动态故障色轻点缀，故障只出现在关键标题和卡片悬停。
- 区块采用“明显但不刺眼”的分区：色带 12%-18%，靠中性黑场和顶部光弧区分。

## 2. 非目标

- 不做移动端适配，保留 `min-width: 1200px`。
- 不实装项目筛选逻辑、博客文章列表、评论或搜索。
- 不引入框架、构建工具、CDN、位图素材或新字体文件。
- 不实现真实折射（SVG displacement map），只用 CSS 可稳定实现的全套玻璃质感。

## 3. 配色系统

### 3.1 比例

- 60%：深色中性底，作为整页舞台。
- 30%：区块色带、卡片和玻璃表面。
- 10%：霓虹、故障色、CTA、活动状态。

### 3.2 页面强调色

每个页面最多使用 2 个强调色：

| 页面 | 主强调色 | 次强调色 |
|---|---|---|
| 首页 | 青 + 紫 | 青绿 |
| 关于我 | 紫 | 青 |
| 项目 | 品红 | 紫 |
| 学习日记 | 青 | 青绿 / 绿 |
| 博客 | 琥珀 | 青 |

### 3.3 颜色表

- 青：`#00E5FF`
- 紫：`#A855F7`
- 青绿：`#2DD4BF`
- 品红：`#F472B6`
- 琥珀：`#FBBF24`
- 绿：`#34D399`

所有颜色以 rgba 淡色形式用于区块背景，全亮色只用于文字强调、边框发光和 CTA。

## 4. 玻璃材质系统

### 4.1 三级玻璃

| 级别 | 用途 | blur | 饱和度 | 透明度 |
|---|---|---|---|---|
| `glass-sm` | 角标、筛选按钮、小胶囊 | 8px | 1.3 | 约 20% |
| `glass-md` | 卡片、时间线卡片、项目卡片 | 18px | 1.5 | 约 42% |
| `glass-lg` | 导航、CTA 面板、放大弹层 | 26px | 1.7 | 约 62% |

### 4.2 玻璃层构成

每块玻璃由以下 5 层组成：

1. 半透明深色渐变底。
2. 1px 白青色细边框。
3. 顶部 1px 内高光，模拟受光面。
4. 左上柔和高光斜线，模拟环境反射。
5. 底部深色投影和内侧暗影，模拟玻璃厚度。

### 4.3 圆角

- 卡片：18-20px。
- 按钮：10-12px。
- 胶囊按钮：999px。

### 4.4 可读性

- 长文本不直接放在薄玻璃上。
- 关于我、博客等阅读型卡片使用 `glass-md`，并加强底色和正文文字投影。
- 玻璃后面必须保留局部颜色和细节，否则模糊效果不可见。

## 5. 区块与布局

### 5.1 结构

主要区块统一使用：

```html
<section class="zone zone-xxx">
  <div class="zone-inner">
    <!-- 原内容 -->
  </div>
</section>
```

- `.zone`：全宽，负责色带和光弧。
- `.zone-inner`：最大宽度 1160px，水平内边距 24px。
- `#full-timeline`、`#home-timeline`、`#particles` 等 ID 保持不变。

### 5.2 区块分隔

- 区块之间保留 48-64px 中性深色空档。
- 每个区块顶部有 1-2px 渐变光弧。
- 光弧上有缓慢移动的扫光亮点，周期 8-10 秒。

### 5.3 HUD 标签

- 现有 kicker 加 `hud-kicker` 样式。
- 用 CSS counter 自动生成 `SYS.01 / DIARY` 格式，HTML 不写死编号。
- 字体使用 `ui-monospace, 'Cascadia Mono', Consolas, monospace`。

## 6. 背景系统

- body 改为中性深色底，移除全屏青紫光斑和大部分星点网格。
- 保留局部细节：区块色带、一层稀疏星点、2 个透明度 5%-8% 的柔光。
- 粒子数量从 40-50 降到 20-26。
- 亮星比例约 12%。
- 移除鼠标网格 `#cursor-grid` 的 CSS 和 JS 初始化。

## 7. 动态故障色

- 用纯 CSS 实现：`data-text` + 伪元素 + `clip-path` + keyframes。
- 应用到首页大标题、各页主标题、区块标题悬停。
- 效果为 0.3-0.4 秒 RGB 色偏和轻微位移。
- 按约 9 秒周期出现一次，不持续闪烁。
- 卡片悬停时边框光弧在青、品红、琥珀之间短暂切换。
- 故障伪元素 `pointer-events: none`，不改变布局。

## 8. 动效规则

- 页面进入：保持错落渐显。
- 区块入场：轻微上移渐显，不做强缩放。
- 卡片悬停：上浮 2-4px、边框发光、高光跟随鼠标。
- 高光跟随鼠标通过 `--gx/--gy` 变量实现，由 `js/main.js` 中的 `initGlassSheen()` 维护。

## 9. 可访问性与降级

- `prefers-reduced-motion: reduce`：关闭粒子、扫光、故障、滚动动画。
- `prefers-reduced-transparency: reduce`：玻璃改为近实色深底，降低或关闭模糊。
- `@supports not (backdrop-filter)`：使用近实色深底，保持可读。

## 11. 验收标准

- 桌面宽度 1200px 和 1440px 下，5 个页面均正常。
- 每页最多 2 个强调色，区块颜色差异明显。
- 区块顶部光弧和 `SYS` HUD 标签可见。
- 卡片有真实清透玻璃质感，文字无重叠且可读。
- 时间线点击放大、首页统计、导航、页脚、卡片高光均正常。
- 浏览器控制台无报错，CSS、JS、图片、字体请求全部 200。
- reduced-motion 和 reduced-transparency 降级正常。
