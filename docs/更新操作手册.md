# memory-site 更新操作手册

> 适用对象：网站作者与 AI 维护者
> 更新日期：2026-08-11

## 1. 页面与文件

| 页面 | 文件 | 主要维护点 |
|---|---|---|
| 首页 | `index.html` | 自我介绍、按钮、统计数字、精选项目 |
| 关于我 | `about.html` | 头像、简介、技能、联系方式 |
| 项目作品集 | `projects.html` | 项目卡片 |
| 学习日记 | `diary.html` | 自动读取 `js/main.js` 中的数据 |

全站样式在 `css/style.css`，全站脚本和学习日记数据在 `js/main.js`。

## 2. 修改学习日记

打开 `js/main.js`，找到 `timelineData` 数组。每项是一条记录，按时间升序排列，新的放后面：

```js
{
  time: "2026.08.02",           // 年月日，格式为 YYYY.MM.DD
  title: "今天学了什么",         // 一句话标题
  desc: "一两句补充说明"         // 说明
}
```

修改后刷新页面即可看到；发布线上见第 5 节。学习日记不包含外部链接，点击卡片会在站内放大查看完整内容。

## 3. 修改其他内容

- 首页：`index.html` 中的 `data-count` 是统计数字，改项目数、文章数时同步修改。
- 关于我：直接改 `about.html` 中的头像、简介、技能和联系方式。
- 项目：直接改 `projects.html` 中的项目卡片。筛选按钮目前只是视觉装饰，筛选逻辑未实装。
- 图片：把文件放入 `images/`，在 HTML 中引用 `images/文件名`。
- 字体：`fonts/Inter-latin-variable.woff2` 是本地正文字体，`fonts/SmileySans-Oblique.ttf.woff2` 是本地得意黑（仅用于关键标题，如 `.hero-title`、`.page-title`、`.section-title`、`.cta-section h2`、`.tl-title`），均不要改成外部 CDN。
- 样式与配色：全部在 `css/style.css`，颜色、圆角、阴影等集中在 `:root`。
- 玻璃分级：`glass-sm` 用于角标与筛选按钮，`glass-md` 用于卡片与时间线卡片，`glass-lg` 用于导航、CTA 与放大弹层；全站统一使用暖金单高光，不再按页面切换强调色。
- 日记滑条：学习日记页横向时间线下方有左右箭头和进度条，由 `js/main.js` 自动生成，无需手动维护。

## 4. 本地预览

- 方法一：直接双击 `index.html`。
- 方法二：在项目根目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。
- 检查 4 个页面、图片与字体、浏览器控制台是否有报错。

## 5. 发布到 Netlify

当前状态：

- 线上地址：`https://memory-site-903.netlify.app/`
- 当前部署方式：手动上传，未关联 GitHub 自动部署。
- 最近一次部署：2026-08-11，UI 视觉升级版已上线。

手动部署步骤：

1. 本地修改完成并保存。
2. 在项目根目录运行：`netlify deploy --prod --dir .`
3. 如果没有 `netlify` 命令，用 `npx netlify deploy --prod --dir .`。
4. 打开线上地址确认页面正常。

推荐以后接入自动部署：

1. 在 Netlify 控制台导入 GitHub 仓库 `moxiao954/memory-site`。
2. 构建命令留空，发布目录指向仓库根目录。
3. 之后本地改动推送到 GitHub，Netlify 会自动重新部署。

## 6. 代码备份

- 也可以使用 GitHub Desktop 完成。
- `.netlify/` 是本地部署状态，已在 `.gitignore` 中，不要提交。
